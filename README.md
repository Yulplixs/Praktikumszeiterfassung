# Praktikumszeiterfassung

Schulprojekt zur zeitlichen Erfassung von Praktikumszeiten

## Projektstruktur

- `src/`: HTML-Seite und CSS-Quelltexte
- `public/`: öffentlich verwendete Assets, derzeit das BBS-Einbeck-Logo
- `index.html`: Einstiegspunkt für lokale Vorschau und statisches Hosting
- `CHANGELOG.md`: Änderungen am Projekt

Das Projekt wird derzeit ohne Build-Schritt betrieben. Ein `dist/`-Ordner sowie
Konfigurations-, Datenbank- und Testordner sind deshalb nicht erforderlich.
